# Declarative automation examples

The `templates/` folder contains starter implementations for seven executable languages and safe read-only samples for SQL, Terraform, Ansible and YAML.

These are **not included in the implemented-script count**. They must be adapted to a real use case, reviewed, tested and registered in the catalog before they become official automations.

A Terraform plan can still read cloud metadata and write local state; review it before applying. SQL examples use PostgreSQL syntax with parameter placeholders. Ansible examples should be run only against authorized hosts.
