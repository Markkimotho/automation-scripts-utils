# Automation Scripts & Utils

A practical automation library you can install and use from any terminal.

```bash
pipx install git+https://github.com/Markkimotho/automation-scripts-utils.git
automation search "backup"
automation info incremental-file-copy
automation run incremental-file-copy --dry-run
```

## Find an automation
